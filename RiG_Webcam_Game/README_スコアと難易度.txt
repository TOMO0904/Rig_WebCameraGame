RiG++ アドカレ2026「HAND DODGE+」 スコア・難易度アップデート
=====================================================

【まず大事】
今動いているPython 3.13.5、.venv-existing、手認識モデルをそのまま使います。
Python本体もMediaPipeも入れ直さないでください。

【既存ゲームを更新する場合】
1. いま使っている RiG_Webcam_Game フォルダのコピーをバックアップとして保存
2. このZIPを「すべて展開」
3. 展開先の webcam-game フォルダ内にある main.py と game_logic.py を、
   いま使っている RiG_Webcam_Game\webcam-game\ にコピーして上書き
4. start-webcam-easy.bat、start-webcam-hard.bat、start-game-difficulty-menu.bat を
   いま使っている RiG_Webcam_Game フォルダの直下にコピー
5. start-game-difficulty-menu.bat をダブルクリックして、1〜3で難易度を選んで開始

※ models フォルダ、.venv-existing フォルダは絶対に消さないでください。
※ ZIPを別フォルダへ展開して新しく起動すると、ライブラリの再導入が必要になります。
※ 既存の start-webcam-game.bat は NORMAL モードとして引き続き使用できます。

【新しいルール】
・手を左右に動かして宇宙船を動かす。落ちてくる赤い障害物を避ける
・一定時間生き残ると少しずつスコアが入る
・障害物を下まで通過させると +10 x LEVEL x COMBO倍率
・4連続回避で2倍、8連続で3倍、12連続で最大4倍
・ぶつかるとコンボはゼロに戻る
・黄色い星を取ると +40 x LEVEL の得点ボーナス
・水色のSアイテムを取ると12秒間のシールド（1回の衝突を無効化）
・NORMALは20秒ごとにレベルアップ。段階的に落下スピードと頻度が増加
・手を認識できなくなったら一時停止
・ゲームオーバー後は画面の中央に手を1.5秒保持して再スタート
・終了はQまたはEscキー

【難易度】
EASY: 5ライフ、障害物が遅く少ない、25秒ごとにレベルアップ
NORMAL: 3ライフ、標準スピード、20秒ごとにレベルアップ
HARD: 2ライフ、障害物が速く多い、16秒ごとにレベルアップ

【ハイスコア】
終了時やゲームオーバー時に、webcam-game\highscores.json に難易度別に保存。
本人のPCに数字のみを保存します。カメラ映像は保存・送信しません。
書き込み不可の場合は画面上のスコアは動作しますが、終了時の保存はできません。

【実装・公開】
変更したのは main.py（画面・カメラ・保存）と game_logic.py（ゲームルール）。
カメラ認識コードは以前の動作済み版と同じ。
GitHubへの公開はまだ行っていません。
