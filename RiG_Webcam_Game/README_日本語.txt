RiG++ Windows Webカメラゲーム - インストール済みPython対応版

Python 3.11 を新しくインストールする必要はありません。
すでにインストールされている64bit Python 3.9〜3.14を検出して利用します。

1. ZIPを右クリックし「すべて展開」する（ZIPの中から直接実行しない）。
2. RiG_Webcam_Game フォルダを開く。
3. start-webcam-check.bat をダブルクリックして映像を確認する。
4. カメラ番号は通常 0。映らなければ 1。
5. Q または Esc で終了。
6. start-webcam-game.bat をダブルクリックして手を左右に動かす。
7. カメラ1のゲームは start-webcam-camera1.bat を使用する。

初回起動では環境を作り必要なPythonパッケージをダウンロードします。
インストール済みのPython本体に変更はしません。
ダウンロードに失敗した場合は、ターミナル上のエラー全文をスクリーンショットで共有してください。

もしPythonが見つからない場合:
 Windows ターミナルで py --list-paths と python --version を実行してください。
